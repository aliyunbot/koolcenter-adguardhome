# Branding

The software-center icon is an adapted shield crop based on the official AdGuard Home dark-mode artwork:

- Source: https://raw.githubusercontent.com/AdguardTeam/AdGuardHome/master/doc/adguard_home_darkmode.svg
- Upstream project: https://github.com/AdguardTeam/AdGuardHome
- Local source: `assets/adguardhome-shield.svg`
- Package asset: `package/adguardhome/res/icon-adguardhome.png`

Only the shield mark is used in the package UI. The AdGuard Home wordmark is not bundled, and the package does not bundle the AdGuard Home binary.
